untuk MAC : 

1. install homebrew buka terminal lalu ketik : /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
2. masukan password mac, kemudian tunggu install.
3. install python : brew install python@3.9
4. brew install cmake boost boost-python dlib
5. python3 -m venv dlib_env
6. source dlib_env/bin/activate
7. pip install dlib
