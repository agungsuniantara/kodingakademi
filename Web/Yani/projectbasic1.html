Mengenal Pengertian Website, Ketahui Jenis dan Fungsinya

Merdeka.com- Website adalah kumpulan halaman web yang dapat diakses publik dan saling terkait yang berbagi satu nama domain. Website dapat dibuat dan dikelola oleh individu, grup, bisnis, atau organisasi untuk melayani berbagao tujuan. Bersama-sama, semua website yang dapat diakses public membentuk World Wide Web. Meskipun terkadang disebut "halaman web", definisi ini salah, karena website terdiri dari beberapa halaman web. Website memiliki variasi yang hampir tidak ada habisnya, termasuk situs pendidikan, situs berita, forum, situs media sosial, situs e-commerce, dan sebagainya. Halaman-halaman dalam sebuah website biasanya merupakan campuran teks dan media lainnya. Meskipun demikian, tidak ada aturan yang mengatur bentuk website. Untuk melihat halaman website membutuhkan sebuah browser. Contoh browser diantaranya sebagai berikut :

  1. Internet Explorer
  2. Edge
  3. Safari
  4. Chrome
